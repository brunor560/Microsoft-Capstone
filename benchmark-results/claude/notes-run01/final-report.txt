### Unclear requirements / interpretations

- UI-02 says "each line break in the notes starts a new line" — interpreted as `\n` → `<br>` (not `<p>` tags).
- The spec says links must start with `https://…` or `http://…`; the regex enforces this, so `javascript:` and other schemes are rejected silently (the raw text is shown instead), which also satisfies the security requirement.

### Unexpected findings

The existing `index.html` used `${item.title}` directly inside an innerHTML template string with no escaping — a stored XSS vector. I fixed this in the same pass by routing all user-sourced text through `escapeHtml()`.
