Agentic Development for Software Engineering

An Empirical Evaluation and Benchmarking Framework for End-to-End AI Developer Loops

View Requirements Project Repository

Project Overview

Business Problem & Epic

Epic Question: How can software engineering teams systematically evaluate and benchmark end-to-end agentic developer loops across distinct platforms against a common full-stack application to measure task success, code security, and token operational costs under strict resource limits?

Proposed Solution

An automated benchmarking pipeline that feeds standardized backlog demand items into both Microsoft and competing agent harnesses, recording empirical telemetry from initial prompt to pull request.

  • Standardized full-stack testbed (UI, API, persistence)
  • Automated prompt-to-PR agent orchestration
  • Security boundary and zero-token-leak scans
  • Cost and runtime telemetry tracking

Pillars & Core Features

Feature 1: Evaluation Testbed

A standardized full-stack reference application (UI, REST API, Database) deployed in containerized sandboxes for reproducible agent task execution.

Feature 2: Multi-Ecosystem Loops

Automated integration comparing Microsoft/GitHub loops (Copilot Workspace, AutoGen) against industry alternatives (Cursor, Devin, LangGraph).

Feature 3: Security & Governance

Adversarial prompt-injection defenses, least-privilege tool execution, and automated scanning to prevent credential leakage in commits.

Feature 4: Telemetry & Cost Modeling

Granular tracking of token consumption, model tier pricing, and runtime latency to build a data-driven adoption matrix and white paper.

Evaluation Criteria

Execution Success
Automated Test Pass Rate
Security Posture
Zero Credential Leaks
Cost Optimization
Tokens per Resolved Task
Autonomy Level
Minimal Human Intervention
