# Status report template

Agent-readable equivalent of the supplied [status report template](../originals/status_report_template.doc). The supplied file was filled in with the team's project name, week number, and member list; those are left as placeholders here.

File name convention from the template: `statusName_MonthDayYear.doc`.

## Status Report for Project Name: [project/team] for Week #[N]

Members:

1. [Member name], Primary Role: [role]
2. [Member name], Primary Role: [role]
3. [Member name], Primary Role: [role]
4. [Member name], Primary Role: [role]

### What were the goals for this period?

Be specific. Enumerate the goals for the past period. Goals must be measurable and connected to the requirements.

### What goals were accomplished in the current period?

Enumerate what was completed successfully in this period.

### Reflect critically on any goals not accomplished.

Explain why any missed goals were not completed and what the plan is for them going forward.

### What are the goals for the next two weeks / period?

Enumerate the goals for the next two weeks or period. Goals must be measurable and connected to the requirements.

**Reminder from the template: ensure the timesheet is completed weekly by each member.**
