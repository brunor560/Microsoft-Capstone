# System Requirements Specification template

Agent-readable equivalent of the supplied [SRS course template](../originals/srs_template.docx). It is a structure guide: bracketed fields are placeholders, and the original's sample content (a footbridge example) is not reproduced and is not project content. Use the original template's styles and fonts for Word exports; the instructor asks for them so documents are easy to read.
